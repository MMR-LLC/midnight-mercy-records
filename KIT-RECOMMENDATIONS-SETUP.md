# Disable Kit's post-signup creator recommendations

This popup is controlled by the Kit account, not by the website files.

1. Sign in to Kit.
2. Open **Grow → Recommendations**.
3. Open **Settings** in the Recommendations area.
4. Choose **Turn off Recommendations** and confirm.
5. Test the website form again in a private/incognito browser window with a new email address.

If Kit does not allow Recommendations to be disabled on the current plan, the remaining options are to upgrade the Kit plan or use a different form workflow. Do not hide or block the Kit popup with website CSS or JavaScript because it is rendered and controlled by Kit after submission.
